# Sales Performance Analysis

## 📊 Project Overview

Sales Performance Analysis is an Excel-based data analysis project developed to analyze sales transactions and identify trends in revenue, product performance, regional performance, and salesperson performance.

The project uses Excel formulas, VLOOKUP, Pivot Tables, Pivot Charts, KPIs, and slicers to transform raw sales data into an interactive dashboard.

## 🛠️ Tools & Technologies

- Microsoft Excel
- VLOOKUP
- SUMIF / SUM
- COUNTIF / COUNTA
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Visualization
- Dashboard Design

## 📁 Dataset
![Sales Performance Dashboard](dashboard.png)

The dataset contains sales transaction information including:

- Order ID
- Order Date
- Region
- Salesperson
- Product
- Category
- Quantity
- Unit Price
- Revenue

## 🔍 Analysis Performed

The project analyzes:

- Regional revenue performance
- Product revenue performance
- Monthly revenue trends
- Salesperson performance
- Sales quantity
- Average order value

## 📈 Dashboard

The Excel dashboard contains:

- Total Revenue KPI
- Total Orders KPI
- Total Quantity KPI
- Average Order Value KPI
- Revenue by Region chart
- Revenue by Product chart
- Monthly Revenue Trend
- Sales by Salesperson chart
- Interactive slicers
- Key business insights

## 💡 Key Insights

- South is the highest-revenue region.
- Laptop is the highest-revenue product.
- Mouse has the highest quantity sold.
- December has the highest monthly revenue.
- Rahul is the top salesperson by revenue.
